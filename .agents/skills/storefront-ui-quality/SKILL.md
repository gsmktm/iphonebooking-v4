# storefront ui quality

Trigger: React/CSS, catalog, comparison, checkout, mobile, account and admin UX changes.

- Use one coherent editorial visual system: navy/ink, warm neutrals, antique gold accents and genuine product imagery.
- Derive prices, product options, availability, reviews and offers from approved server records.
- Verify 320px/390px mobile, tablet and desktop. Check labels, keyboard, focus, touch targets, reduced motion, empty and error states.
- Measure LCP, INP, CLS and image layout stability instead of assuming performance.
- Exercise actual customer journeys and axe accessibility checks in Playwright staging with synthetic accounts. Keep production QA read-only.

Influenced by nextlevelbuilder/ui-ux-pro-max-skill, Leonxlnx/taste-skill, anthropics/skills frontend-design, ECC browser-qa, and addyosmani frontend engineering.
